# Аудит сторонних библиотек и лицензионная политика

## 1. Лицензионные ограничения

Проект **GeoWeedStation** предназначен для коммерческого и промышленного применения. В кодовой базе и зависимостях действует строгий регламент:

> [!CAUTION]
> **Полный запрет на лицензии семейства AGPL (GNU Affero General Public License)** и вирусные copyleft-лицензии (GPL без исключений). Запрещено прямое подключение пакетов `ultralytics` (AGPL-3.0) и `PyQt` (GPL-3.0).

## 2. Реестр используемых библиотек

| Библиотека | Назначение в проекте | Лицензия | Совместимость |
|---|---|---|---|
| `PySide6` | Графический интерфейс Qt6 | LGPLv3 | Разрешено (динамическая линковка) |
| `onnxruntime` | Нейросетевой инференс моделей | MIT | Пермиссивная (Permissive) |
| `opencv-python-headless` | Декодирование видео и обработка матриц | Apache-2.0 | Пермиссивная |
| `numpy` | Математические расчеты, матрицы растров | BSD-3-Clause | Пермиссивная |
| `scipy` | Kernel Density Estimation, выпуклые оболочки | BSD-3-Clause | Пермиссивная |
| `pydantic` | Валидация DTO и структур данных | MIT | Пермиссивная |
| `pydantic-settings` | Управление файлами конфигурации | MIT | Пермиссивная |
| `requests` | HTTP REST API клиент к борту | Apache-2.0 | Пермиссивная |
| `pyproj` | Картографические проекции (EPSG) | MIT | Пермиссивная |
| `Pillow` | Работа с растровыми изображениями | HPND (MIT-like) | Пермиссивная |
| `fastapi` | Локальный мок-сервер для тестов | MIT | Пермиссивная |
| `uvicorn` | ASGI-сервер для мок-борта | BSD-3-Clause | Пермиссивная |
| `pytest`, `pytest-qt` | Набор автоматических тестов | MIT | Пермиссивная |
| `pyinstaller` | Сборка бинарных релизов | GPLv2 with Special Exception | Разрешено для утилит сборки |
