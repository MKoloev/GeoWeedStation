# Архитектура связи и регламент интеграции GeoWeedStation с дроном Skyris

Настоящий документ фиксирует результаты аппаратной диагностики бортового комплекса **Skyris (Orange Pi 5 Pro / Technic 6S)**, описывает проверенные каналы взаимодействия и определяет детальный план модернизации рабочей станции **GeoWeedStation** для запуска автономных миссий и отображения видеопотока с разметкой нейросети.

---

## 1. Сводные параметры дрона и сетевые интерфейсы

Все параметры верифицированы на реальном аппаратном комплексе со снятыми пропеллерами и в автономном прогоне:

| Параметр | Значение | Примечание |
|---|---|---|
| **IP-адрес дрона** | `10.42.0.1` | Статический IP точки доступа Wi-Fi дрона |
| **SSH-доступ** | Порт `22`, пользователь `orangepi`, пароль `orangepi` | Доступ к командной оболочке и SFTP |
| **Каталог ПО на дроне** | `/home/orangepi/tsu/CollectOnboardImage` | Рабочий каталог бортового модуля сбора и детекции |
| **Видеосервер (ROS)** | Порт `8080` (`web_video_server`) | HTTP-сервер для отдачи MJPEG и JPEG снимков |
| **Топик детекции YOLO** | `/yolo/debug` | Стандартный ROS Image топик с наложенным HUD и боксами |
| **Топик детекции бортовой** | `/collect_onboard_image/debug` | Выделенный топик модуля сбора данных ($1280 \times 960$) |

| **Нейропроцессор (NPU)** | Rockchip RK3588S (3 ядра, 6 TOPS INT8) | Модель `yolox_m_rk3588_int8.rknn` (~72 мс/кадр) |

## 2. Проверенные каналы связи (Communication Matrix)

```
+-------------------------------------------------------------------------+

|                                                                         |

|  |  [Виджет видеопотока]  |◄────────────|  StreamWorker (HTTP 8080)  |  |
|  +------------------------+             +----------------------------+  |
+-------------------------------------------------------------------------+
          │ (Команда запуска & логи)            │ (MJPEG / JPEG кадры)

          ▼                                     ▼
+-------------------------------------------------------------------------+
```

### 2.1. Канал управления миссией (SSH / SFTP)
- **Протокол:** SSH2 через библиотеку `paramiko` (уже установлена в виртуальном окружении).
- **Команда запуска миссии:**
  ```bash
  bash -l -c "cd /home/orangepi/tsu/CollectOnboardImage && python3 main.py \
    --input-dir data_image/06_geosaero_corner_25_wgs84_10pct_aruc_ex \
    --model models/yolox_m_rk3588_int8.rknn \
    --waypoints waypoints/zigzag_skyris.json \
    --geotag-mode drone_telemetry \
    --altitude 2.0 \
    --speed 0.5 \
    --hover-delay 1.0 \
    --nav-timeout 20.0 \
    --conf-thresh 0.35"
  ```
- **Преимущества прямого SSH-запуска:**
  1. **Не требует установки сторонних демонов:** На дроне ничего не нужно доустанавливать, интернет не требуется.
  2. **Потоковый лог:** Вывод `stdout` и `stderr` передается в GUI в реальном времени.
  3. **Надежное прерывание:** При нажатии кнопки «Экстренная посадка» отправляется сигнал `SIGINT` (Ctrl+C), по которому скрипт корректно вызывает сервис посадки `land()`.
  4. **Выгрузка отчетов по SFTP:** По завершении файлы `summary.json`, `manifest.json` и изображения скачиваются по стандартному протоколу SFTP.

### 2.2. Канал видеопотока и детекции (HTTP / web_video_server)
- **URL потока (MJPEG):**
  `http://10.42.0.1:8080/stream?topic=/yolo/debug` (или `/collect_onboard_image/debug`)
- **URL одиночного кадра (JPEG Snapshot):**
  `http://10.42.0.1:8080/snapshot?topic=/yolo/debug`
- **URL веб-просмотрщика:**
  `http://10.42.0.1:8080/stream_viewer?topic=/yolo/debug`
- **Параметры кадра:** разрешение $1280 \times 960$, частота 1–5 кадров/с, кодирование BGR8 $\to$ JPEG, наложен верхний HUD-баннер и рамки сорняков.

## 3. Детальный план реализации в GeoWeedStation

### Этап 1: Создание воркера видеопотока `LiveDebugStreamWorker`
- **Файл:** `src/geo_weed_station/workers/live_stream_worker.py`
- **Механизм:**
  - Фоновый поток `QThread`, опрашивающий `http://10.42.0.1:8080/snapshot?topic=/yolo/debug` с заданной частотой (например, 2–4 Гц) или читающий непрерывный MJPEG-поток `stream?topic=/yolo/debug`.
  - Преобразует полученные JPEG-байты в `QImage` / `QPixmap`.
  - Эмитирует сигнал `frame_ready(QPixmap)` в UI.
  - Обрабатывает таймауты и дисконнекты: если дрон не вещает (например, миссия еще не начата), эмитирует статус `waiting_for_stream` и показывает экран ожидания.

### Этап 2: Создание виджета видеомониторинга `LiveStreamWidget`
- **Файл:** `src/geo_weed_station/ui/widgets/live_stream_widget.py`
- **Функционал:**
  - Окно отображения последнего кадра с сохранением пропорций (Aspect Ratio).
  - Индикатор состояния: «🟢 В эфире / 🟡 Ожидание потока / 🔴 Нет связи».
  - Переключатель топиков: `/yolo/debug` / `/collect_onboard_image/debug`.
  - Кнопка быстрого снимка (Save Snapshot) на диск станции.

### Этап 3: Создание воркера запуска миссии `SshMissionWorker`
- **Файл:** `src/geo_weed_station/workers/ssh_mission_worker.py`
- **Функционал:**
  - Асинхронное подключение к `10.42.0.1` через `paramiko`.
  - Исполнение команды запуска бортового комплекса.
  - Построчный перехват консольного вывода: сигналы `log_received(str)`, `progress_updated(int, int)`.
  - Сигнал `mission_finished(bool, str)`.
  - Метод `abort_mission()`: отправка сигнала `SIGINT` в канал для штатной автопосадки дрона.
  - Скачивание результатов миссии в локальный каталог `workdir/runs/`.

### Этап 4: Модернизация вкладки «Миссия» (`MissionControl`)
- **Файл:** `src/geo_weed_station/ui/widgets/mission_control.py`
- **Изменения:**
  - В праpanel или нижнюю часть экрана встраивается `LiveStreamWidget`.
  - Добавляется крупная заметная кнопка: **«🚀 Запустить миссию на дроне»**.
  - Добавляется кнопка **«⬇ Прервать / Посадка (Land)»**.
  - Добавляется консольное окно вывода бортовых логов миссии (`QPlainTextEdit`) для контроля этапов: взлет, облет точек, детекция, возврат домой.

### Этап 5: Сквозная интеграция в `OnlineController`
- **Файл:** `src/geo_weed_station/controllers/online_controller.py`
- Связывание сигналов `MissionControl`, `SshMissionWorker` и `LiveDebugStreamWorker`.
- После завершения полета автоматический вызов парсинга `summary.json` и отрисовка найденных сорняков на вкладке «Карта» и «Запуски».
