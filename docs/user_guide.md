# Руководство оператора GeoWeedStation

## 1. Введение и запуск программы

**GeoWeedStation** — десктопное приложение оператора (GCS) для автоматизации мониторинга сорной растительности, планирования полетных заданий БПЛА и построения цифровых карт полей.

### Запуск приложения:
```bash
./geoweedstation.sh
# либо через Python:
python main.py
```

---

## 2. Переключение глобальных режимов работы

В верхней панели окна расположен селектор режимов:
- **Офлайн-режим (Offline)**: предназначен для обработки аэрофотоснимков с SD-карты, папок с сессиями и видеофайлов. Сетевые панели скрываются.
- **Онлайн-режим (Online)**: предназначен для прямого взаимодействия с бортовым комплексом `agrovision_onboard` по Wi-Fi/Ethernet REST API.

---

## 3. Работа в Офлайн-режиме

### 3.1 Обработка одиночного снимка
1. Выберите в меню **Файл → Открыть изображение** (`Ctrl+O`).
2. Снимок отобразится на вкладке **«Изображение»**.
3. Программа автоматически выполнит локальный нейросетевой инференс и наложит рамки найденных сорняков.
4. При наличии XMP-геопривязки координаты объектов будут добавлены на вкладку **«Карта»**.

### 3.2 Пакетная обработка каталога снимков
1. Выберите **Файл → Открыть папку**.
2. В боковой панели **«Пакетные файлы»** появится список всех найденных снимков с их статусами и признаком XMP.
3. Нажмите кнопку **«⚡ Запустить обработку»**.
4. В строке состояния будет отображаться прогресс выполнения (0..100%).
5. По завершении точки сорняков и тепловая карта автоматически появятся на вкладке **«Карта»**.

### 3.3 Просмотр и анализ видео
1. Выберите **Файл → Открыть видео**.
2. Перейдите на вкладку **«Видео»**.
3. Доступны кнопки **Play / Pause**, перемотка по таймлайну и выбор шага пропуска кадров (1x, 2x, 5x, 10x).

---

## 4. Работа в Онлайн-режиме (Борт БПЛА)

### 4.1 Подключение к бортовому комплексу
- Программа автоматически опрашивает борт по адресу, заданному в настройках (по умолчанию `192.168.4.1:8000`).
- Статус в нижней строке меняется: `CONNECTING → CONNECTED`.

### 4.2 Планирование полетного задания
1. Перейдите на вкладку **«Миссия»**.
2. Задайте координаты угловых точек полетной зоны (TL и BR).
3. Укажите высоту съемки $H$ (например, 10 м) и процент перекрытия кадров (например, 20%).
4. Выберите режим:
   - **Сбор данных (без ИИ)** — быстрая съемка, снимки сохраняются на борт;
   - **Последовательный бортовой ИИ** — дрон выполняет детекцию на борту в каждой точке.
5. Нажмите **«📐 Рассчитать маршрут»** — на карте отобразится змейка облета.
6. Нажмите **«🚀 Отправить задание и Старт»**.

### 4.3 Мониторинг телеметрии и регламент 10 минут
- В панели **«Телеметрия БПЛА»** отображаются текущий этап полета, индекс точки, высота и координаты.
- На карте маркер дрона и вектор оптической оси перемещаются в реальном времени.
- **Внимание**: регламентный полетный слот составляет **не более 10 минут**. При превышении времени в строке состояния появится предупреждение.

### 4.4 Экстренная остановка
В любой момент полета доступны кнопки:
- **«⬇ Посадка (Land)»** — немедленная посадка в текущей точке;
- **«🏠 Возврат домой (RTH)»** — прерывание миссии и возврат в точку старта.

### 4.5 Управление запусками (Вкладка «Запуски»)
- Таблица содержит историю всех выполненных бортовых сессий.
- Оператор может скачать ZIP-архив запуска (**«📥 Скачать архив»**), запустить повторную локальную обработку (**«⚡ Обработать локально»**) или очистить флеш-память борта (**«🗑 Удалить с борта»**).

---

## 5. Экспорт данных картографирования

1. Нажмите кнопку **«Экспорт»** на панели инструментов.
2. В диалоге выберите требуемые форматы:
   - **CSV**: таблица сорняков с координатами $(X, Y)$ и уверенностью;
   - **GeoJSON**: стандартный векторный слой для ГИС (QGIS, ArcGIS);
   - **PNG**: графическая растровая карта высокого разрешения со шкалой и сеткой.
3. Укажите целевой каталог и нажмите **OK**.
