# GeoWeedStation

**GeoWeedStation** — кроссплатформенная наземная станция управления и агрономического картографирования сорной растительности. Программный комплекс предназначен для планирования миссий, взаимодействия с бортовой системой БПЛА (AgroVision), приема телеметрии, а также локального и потокового анализа аэрофотоснимков с детекцией сорняков и геопространственной привязкой.

---

## 📌 Основные возможности

* **Два режима работы**:
  * **Офлайн**: пакетная обработка аэрофотоснимков (JPEG/TIFF) с извлечением телеметрии из XMP-тегов, локальная детекция через ONNX Runtime, воспроизведение видеопотока с наложением детекций.
  * **Онлайн**: подключение к бортовому REST API, планирование маршрута в локальной системе координат (`local_aruco` / `aruco_local`), мониторинг телеметрии 1–2 Гц, экстренное управление (RTH, Land), скачивание и локальная обработка собранных бортом архивов.
* **Картографический движок (MapEngine)**:
  * Проекция пиксельных координат сорняков на подстилающую поверхность с учетом углов камеры (Roll, Pitch, Yaw), высоты ($H > 0$) и FOV.
  * Построение регулярной плотности засоренности (Heatmap).
  * Экспорт результатов в форматы **CSV**, **GeoJSON** и растровую карту **PNG** с легендой и масштабом.
  * Защита от некорректных данных: автоматическая блокировка картографирования и экспорта с предупреждением оператора при отсутствии валидной геопривязки.
* **Высокая производительность и отзывчивость**:
  * Неблокирующий интерфейс на PySide6 (все тяжелые операции, сеть, инференс и декодирование выполняются в фоновых потоках `QThread`).
  * Защита от нехватки памяти (OOM) при просмотре сверхтяжелых снимков (до 8000×6000).
* **Лицензионная чистота**:
  * Полное отсутствие компонентов под лицензиями семейства AGPL (GPL/AGPL-free core). Используются только пермиссивные лицензии (MIT, Apache 2.0, BSD) и LGPLv3 для PySide6.

## 🚀 Быстрый старт

### Требования
* Python 3.10+
* ОС Linux (Ubuntu 20.04/22.04/24.04+) или Windows 10/11

---

### Автоматическая установка в один шаг

Репозиторий включает кроссплатформенные скрипты, которые автоматически проверяют окружение, системные графические библиотеки (на Ubuntu), создают `.venv`, ставят зависимости и генерируют изолированные лаунчеры.

#### Linux (Ubuntu/Debian)
```bash
# Развертывание окружения и генерация лаунчеров (в корне репозитория):
./setup.sh
# либо через каталог deploy:
./deploy/setup_linux.sh
```

#### Windows 10/11
```cmd
:: Запуск в командной строке (CMD) в корне репозитория:
setup.bat
:: либо через каталог deploy:
deploy\setup_windows.bat
```

---

### Запуск приложения

#### Linux:
```bash
# Стандартный запуск (с изоляцией Qt от конфликтов с темами GNOME/GTK/Wayland):
./run_geoweed.sh

# Запуск со встроенной самодиагностикой компонентов:
./run_geoweed.sh --selftest

# Headless запуск (без дисплея):
./run_geoweed.sh --selftest --offscreen
```

#### Windows:
```cmd
:: Обычный запуск приложения (без консольного окна):
run_geoweed.bat

:: Отладочный запуск (с консольным окном и pause при сбоях):
run_geoweed_debug.bat

:: Запуск встроенной самодиагностики:
run_geoweed_debug.bat --selftest --offscreen
```

---

### Ручная установка (альтернативный способ)
```bash
# Создание и активация виртуального окружения
python3 -m venv .venv
source .venv/bin/activate  # на Windows: .venv\Scripts\activate

# Установка зависимостей и пакета в режиме разработки (editable)
pip install --upgrade pip
pip install -e ".[dev]"

# Запуск
python main.py
```

## 🧪 Тестирование

Проект содержит модульные, интеграционные, нагрузочные (НФТ) и архитектурные тесты.

```bash
# Быстрый прогон модульных тестов
pytest -m "not slow"

# Запуск сквозных E2E-тестов с мок-сервером
pytest -m "e2e"

# Запуск проверки нефункциональных требований (производительность, время отклика)
pytest -m "nfr"

# Проверка соблюдения архитектурных слоев (AST-анализ импортов)
pytest tests/architecture/test_import_rules.py
```

## 📦 Сборка и дистрибуция

Сборка автономного исполняемого файла выполняется через PyInstaller:

```bash
# Запуск автоматической сборки
python deploy/build_app.py

# Либо с помощью скрипта установщика
chmod +x deploy/installer_linux.sh
./deploy/installer_linux.sh
```

Готовый бинарный файл формируется в каталоге `dist/GeoWeedStation/`.
