## 📦 О пакете и автономной структуре

Главная цель этой директории — **полная независимость и воспроизводимость**. Если передать эту папку коллеге, заказчику или развернуть её на сервере/бортовом компьютере дрона:
- Не требуются никакие дополнительные файлы из корня проекта.
- Все вспомогательные библиотеки (архитектуры нейросетей YOLOX и ResNet, функции потерь, метрики, аугментации, загрузчики данных) расположены внутри локальной поддиректории `common/`.
- Для каждой модели предусмотрена своя отдельная подпапка с 4 стандартизированными скриптами:
  1. `train.py` — обучение/дообучение модели на едином JSON-датасете;
  2. `export_onnx.py` — экспорт в универсальный формат ONNX FP32 с валидацией графа;
  3. `export_rknn.py` — квантование в формат RKNN INT8 под процессор Rockchip RK3588 (NPU Orange Pi 5 Pro);
  4. `infer.py` — инференс на снимках с визуализацией рамок и автоматическим расчетом метрик точности.
- Дополнительно в корне папки находится единый диспетчер `run_all.py` для пакетного выполнения любой операции по всем моделям одной командой.

## 🗂 Роль и устройство единого JSON-датасета засоренностей

В соревновании и реальных задачах аэромониторинга данные поступают из множества несовместимых источников:
- Разные форматы аннотаций (YOLO `.txt`, маски семантической сегментации `.png`, COCO `.json`, Pascal VOC `.xml`);
- Разные съемочные сенсоры (обычные RGB-камеры, узкополосные мультиспектральные камеры MicaSense RedEdge, Sequoia, двухсенсорные гибридные комплексы);
- Разная высота полета дрона и масштаб пикселей (GSD от 0.27 мм/px до 18 мм/px);
- Полная разметка (размечены все сорняки) и частичная разметка (размечены только ключевые сорняки, а остальные находятся в фоне).

### Зачем нужен файл `master_dataset.json`?

Файл `master_dataset.json` объединяет **все 14 используемых датасетов** в единый унифицированный реестр:
1. **Единый стандарт аннотаций:** Все границы растений переведены в строгий детекционный формат `[x1, y1, x2, y2]` в пикселях исходного кадра, а также продублированы в COCO-формате (`images`, `annotations`, `categories`).
2. **Спектральная паспортизация:** Для каждого кадра в JSON зафиксирован точный список спектральных каналов (`input_bands`), например `["R", "G", "B"]` или `["MS_R", "MS_G", "MS_RE", "MS_NIR"]`, что исключает ошибки перепутывания каналов при обучении.
3. **Физическое масштабирование GSD (Ground Sampling Distance):** В JSON сохранен коэффициент масштабирования `scale_factor` относительно эталона CoFly-WeedDB ($GSD_{ref} = 0.0018$ м/пиксель). Благодаря этому алгоритм нарезки тайлов гарантирует, что сорняк физического размера 10 см всегда занимает одинаковое количество пикселей в окне детектора $640 \times 640$, независимо от того, с какой высоты летел дрон.
4. **Управление обучающими и валидационными выборками:** Поля `assigned_split` (`train` / `val`) исключают утечку данных (data leakage) между обучением и проверкой.
5. **Модульность:** Каждая обучаемая модель обращается к одному и тому же файлу `master_dataset.json`, фильтруя только предназначенные для неё кадры по полю `applicable_models` или спектральным полосам.

## 💡 Метрики качества понятным языком

Чтобы оценить работу моделей, используются общепринятые метрики компьютерного зрения. Ниже приведено их простое объяснение без заумных терминов:

* **AP50 (Average Precision при пороге совпадения 50%):**  
  *Что означает:* Основная метрика для детекторов сорняков. Она показывает, насколько точно нейросеть обводит сорняки прямоугольными рамками. Если предсказанная рамка перекрывает реальный сорняк хотя бы наполовину (IoU $\ge 0.5$) и класс определен верно — это засчитывается как успех.  
  *Пример:* Значение **0.6712** означает, что модель находит 67.1% сорняков при высокой чистоте предсказаний (минимум ложных срабатываний на грунт, камни и солому).

* **mAP50:95 (Строгая средняя точность):**  
  *Что означает:* Усредненная точность детекции при возрастающих требованиях к идеальности рамки — от 50% до 95% перекрытия с шагом 5%. Показывает, насколько аккуратно модель очерчивает габариты растений.

* **Accuracy (Точность классификации):**  
  *Что означает:* Доля правильно угаданных видов растений из 100 предъявленных растению кропов.  
  *Пример:* Значение **0.9500 (95.0%)** означает, что из 100 встреченных сорняков нейросеть безошибочно определяет ботанический вид у 95 растений.

* **F1-Score (Гармонический баланс):**  
  *Что означает:* Баланс между полнотой (найти все сорняки на поле) и точностью (не перепутать сорняк с комком грязи или тенью). Значения выше 0.8 считаются отличными для агрономии.

* **Удержание точности при квантовании INT8 (% Retention):**  
  *Что означает:* Чтобы запустить нейросеть на бортовом компьютере дрона (Orange Pi 5 Pro с чипом Rockchip RK3588), тяжелые 32-битные числа с плавающей точкой сжимаются в компактные 8-битные целые числа (`INT8`). Удержание точности показывает, сколько процентов качества сохранила модель после такого сильного сжатия.  
  *Пример:* Удержание **99.96%** означает, что после 10-кратного уменьшения веса модели точность упала всего на $0.04\%$, то есть качество осталось практически безупречным.

* **Cosine Similarity (Косинусное сходство выходов):**  
  *Что означает:* Мера математической идентичности работы модели на мощном компьютере с видеокартой и на бортовом чипе NPU дрона. Значение 1.0 — абсолютное совпадение. Значения выше 0.98 подтверждают отсутствие артефактов квантования.

## 🔍 Подробная спецификация по каждой модели

### `d01_rgb_plant`
**Основной детектор растений видимого диапазона RGB**
* **Задача:** Обнаружение всех зеленых растений (сорняков и культур) на стандартных ортофотопланах и фотоснимках БПЛА.
* **Архитектура:** YOLOX-M (Backbone: CSPDarknet, Head: Decoupled Head).
* **Спектральные каналы (3 полосы):** Красный (Red ~660 нм), Зеленый (Green ~560 нм), Синий (Blue ~480 нм).
* **Разрешение на входе:** $640 \times 640$ пикселей.
* **Физический охват окна:** Ровно $1.152 \times 1.152$ метра при масштабе $1.8$ мм/пиксель.
* **Метрики качества:**
  * PyTorch AP50: **0.6712** (на отдельных датасетах до **0.877**)
  * RKNN INT8 AP50: **0.6710** (Удержание: **99.96%**, Cosine Similarity: 0.9996)
  * Размер файла: уменьшен с 289.8 МБ до 26.5 МБ (сжатие **-90.9%**).

---

### `d02_ms3_plant`
**Трехканальный мультиспектральный детектор MS3**
* **Задача:** Локализация растений по мультиспектральным данным сенсоров MicaSense RedEdge / Parrot Sequoia.
* **Спектральные каналы (3 полосы):**
  1. `MS_R` ($668$ нм) — зона максимального поглощения хлорофилла;
  2. `MS_G` ($560$ нм) — пик зеленого отражения листьев;
  3. `MS_NIR` ($842$ нм) — ближний инфракрасный диапазон, где живая растительность отражает свет в 4–6 раз сильнее почвы (основа индекса NDVI).
* **Метрики качества:** PyTorch AP50: **0.5723** ➔ RKNN INT8 AP50: **0.5712** (Удержание: **99.81%**).

---

### `d03_ms4_plant`
**Четырехканальный мультиспектральный детектор MS4**
* **Задача:** Надежное отделение сорняков от пожнивных остатков, сухой травы и мульчи с помощью полосы RedEdge.
* **Спектральные каналы (4 полосы):** `[MS_R (668 нм), MS_G (560 нм), MS_RE (717 нм), MS_NIR (842 нм)]`.
* **Роль полосы RedEdge:** Крайний красный диапазон ($717$ нм) фиксирует резкий скачок отражения клеточной структуры живого листа, безошибочно отсекая сухую солому и грунт.
* **Метрики качества:** PyTorch AP50: **0.5915** ➔ RKNN INT8 AP50: **0.5899** (Удержание: **99.74%**).

---

### `d04_ms5_plant`
**Приоритетный пятиканальный детектор MS5**
* **Задача:** Прецизионная детекция по полному спектру сенсоров MicaSense RedEdge-P / Altum.
* **Спектральные каналы (5 полос):** `[Red, Green, Blue, RedEdge, NIR]`.
* **Преимущество:** Сочетание естественного оптического контраста видимого диапазона (RGB) с мощными спектральными индексами (NDVI/NDRE).
* **Метрики качества:** PyTorch AP50: **0.5532** ➔ RKNN INT8 AP50: **0.5527** (Удержание: **99.92%**).

* **Архитектура:** ResNet50DualHead (общий backbone ResNet-50 и 2 независимые выходные головы).
* **Голова 1 (11 категорий):** Фон, Осот/Бодяк/Латук, Вьюнок, Щирица, Маревые, Канатник, Крестоцветные, Горец, Злаковые, Полынь/Ромашка, Гвоздичные.
* **Голова 2 (5 стадий развития):** Фон, Всходы (семядоли), 2-4 настоящих листа, Взрослое растение, Переросшие (цветение/семена).
* **Метрики качества:**
  * Точность категорий (Accuracy): **0.6619 (66.2%)**;
  * Точность фаз роста (Accuracy): **0.7364 (73.6%)**;
  * Удержание точности в RKNN INT8: **98.70%**.

* **Классы (4 класса):** Фон (`S000`), Кукуруза (`S001`), Свёкла обыкновенная (`S009`), Дурман обыкновенный (`S022`).
* **Метрики качества:** PyTorch Accuracy: **0.9230 (92.3%)** ➔ RKNN INT8 Accuracy: **0.9092 (90.9%)** (Удержание: **98.50%**).

* **Классы (4 класса):** Фон (`S000`), Кукуруза (`S001`), Свёкла (`S009`), Дурман (`S022`).

### Вариант 1. Запуск через единый диспетчер `run_all.py`

Из корня папки `standalone_training`:

```bash
# 1. Запустить проверочный цикл обучения (dry-run) для всех 10 моделей
python run_all.py --action train --dry-run

# 2. Обучить только конкретную модель (например, d01_rgb_plant)
python run_all.py --action train --only d01_rgb_plant --epochs 30 --batch-size 4

# 3. Экспортировать все обученные модели в ONNX FP32
python run_all.py --action export_onnx

# 4. Конвертировать все модели в формат Rockchip RKNN INT8 под Orange Pi 5 Pro
python run_all.py --action export_rknn

# 5. Вычислить метрики точности на тестовом датасете для всех моделей
python run_all.py --action eval
```

### Вариант 2. Индивидуальный запуск по папкам моделей
